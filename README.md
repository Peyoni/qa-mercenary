# QA Mercenary

Professional QA and software testing portfolio website.

> You make the game. I break it before players do.

## About

QA Mercenary is a personal QA portfolio and freelance testing services website created by Nikola Pejić.

The website presents QA services, professional experience, game testing experience, selected project evidence, and contact information.

## QA Experience

- 4.5 years of QA experience in AAA game development
- Development testing
- Functional testing
- Regression testing
- Exploratory testing
- Test cases and QA documentation
- Bug reporting
- Multi-platform game testing
- VR testing

## Game QA

Professional experience includes work on AAA Assassin's Creed projects, including:

- Assassin's Creed Black Flag Resynced
- Assassin's Creed Nexus VR

The portfolio also includes project credit screenshots as supporting evidence of professional QA experience.
